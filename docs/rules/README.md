# ビジネスルール仕様（実装ベース）

このディレクトリは、arujan-fan-site の各機能が**実際にコードでどう動いているか**を、想定していたルールと突き合わせるためにまとめたドキュメントです。

## 経緯

2026-07-15の配信アーカイブを抽出した際、ソロ配信であるはずのオシオンさんの動画が0次会の参加者として抽出される不具合が見つかりました。調査の結果、「参加者抽出条件」として想定していたはずのロジック（ソロ配信を除外する等）が実装されていない箇所があることが判明しました。

同様の「想定と実装のズレ」が他の機能にもないか確認できるよう、各機能の**実装済みルールをコードから正確に書き出し**、file:line 付きで記録しています。想定していたルールと違う場合は、このドキュメントと実装のどちらを直すべきか判断する材料にしてください。

## 方針

- ここに書くのは「コードに実際に書かれているルール」のみ。希望・仕様の理想像は書かない。
- 曖昧な記述をせず、必ず対象ファイルと行番号を添える。
- コードが変わったらこのドキュメントも合わせて更新する（放置すると今回と同じズレが再発する）。
- 未実装・死んでいるコードもそのまま「未実装」として明記する（隠さない）。
